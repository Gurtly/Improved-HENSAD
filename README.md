# HENSAD

Python-based Heat Exchanger Network Synthesis and Design software for pinch analysis.

## Download

Download the latest Windows version from the **Releases** section.

## Features

- Pinch analysis
- Heat cascade calculations
- Composite curves
- Heat exchanger network design
- Stream splitting
- ΔTmin violation checking
- Economic analysis
- Excel export
- PNG export

## Running HENSAD

1. Download the latest HENSAD Windows ZIP from Releases.
2. Extract the ZIP.
3. Run `HENSAD.exe`.
4. Keep the `_internal` folder in the same directory as the executable.
